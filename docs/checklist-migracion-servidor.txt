-------------------------------------------------------------------------------
 0. ANTES DE EMPEZAR (verificar el servidor)
-------------------------------------------------------------------------------
[ ] Versión de Windows del servidor virtual.
      Next.js 16 necesita Node 20.9 o más nuevo, y Node 20+ solo tiene
      soporte oficial en Windows Server 2016 o posterior.
      Si el servidor es 2012 R2 o anterior -> NO migrar ahí: usar otra VM
      (Server 2019/2022) en el mismo host, conectada a Bejerman por la LAN.
[ ] RAM y CPU libres. SQL Server por defecto toma toda la memoria que puede.
      Configurar "max server memory" en SQL Server dejando al menos 2-3 GB
      para Node + MySQL + el sistema. (La app usa ~150 MB; el build de Next
      llega a 1-2 GB por unos minutos.)
[ ] Disco: ~2 GB para node_modules + .next + logs, más MySQL.
[ ] Snapshot / backup de la VM antes de instalar nada.
[ ] Coordinar una ventana de corte fuera de horario (el BP corre 6:30).

 6. ENTRADA DESDE INTERNET PARA WHATSAPP (túnel)
-------------------------------------------------------------------------------
El servidor de Bejerman NO debe tener puertos abiertos a internet. Un túnel
saliente (el servidor se conecta hacia afuera) evita abrir nada en el router.

Opción recomendada: Cloudflare Tunnel (gratis)
[ ] Requiere un dominio propio administrado en Cloudflare (ej. elchilo.com).
[ ] Instalar cloudflared como servicio y publicar SOLO la ruta del webhook:
      bot.elchilo.com  ->  http://localhost:3000
      (idealmente restringir a /api/webhook/whatsapp; el resto del sistema
      queda solo para la red interna).
Alternativa: seguir con ngrok
[ ] Agente oficial de ngrok (no el paquete de npm), instalado como servicio:
      ngrok config add-authtoken <token>
      ngrok service install --config <archivo.yml>   (tunnel a localhost:3000
      con el dominio estático sleep-striking-grower.ngrok-free.dev)
      ngrok service start
[ ] Apagar el ngrok de la PC vieja cuando el nuevo esté andando (el dominio
      estático es uno solo: no puede estar en dos máquinas a la vez).
